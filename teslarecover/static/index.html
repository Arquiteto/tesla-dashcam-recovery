Sign in to Tesla

New Tesla software encrypts clips, and Tesla gives the keys to the car's owner. An Edge (or Chrome) window opens on dashcam.tesla.com: sign in there with your Tesla account, solving the captcha if it asks. When you are back on the dashcam page, the window closes by itself. The sign-in window remembers your Tesla login for next time; this app keeps the access token only while it is open.

Sign-in window not working? Paste a token instead

On dashcam.tesla.com open DevTools → Network, pick any /api/ request and copy the value after Authorization: Bearer.

Decrypt and name the clips

Clips are decrypted on this computer and named by recording time, camera and location.
